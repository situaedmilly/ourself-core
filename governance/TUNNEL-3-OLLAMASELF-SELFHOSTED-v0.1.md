# Tunnel 3 — OLLAMASELF self-hosted realization v0.1

## Purpose

This extension places OLLAMASELF inside a self-hosted execution chamber without transferring constitutional authority to the model runtime, GitHub, or the runner.

## SELFGRAPH

`OURSELF -> AGENTBRIDGE -> HERMES -> OURSELFD -> SELF_HOSTED_RUNNER -> OLLAMASELF`

Return path:

`OLLAMASELF -> AGENTBRIDGE -> OURSELFD -> UNIVERSAL_EVENT_LEDGER -> OURSELF`

## Boundary

The self-hosted runner is realization infrastructure. It is not an authority source.

OLLAMASELF is a cognitive realization surface. It may:

- load or invoke a declared local model;
- generate inference;
- retain declared context;
- emit a proposal;
- request a governed transition.

OLLAMASELF MUST NOT:

- grant authority;
- self-admit;
- self-actuate an externally consequential transition;
- mutate governance;
- redefine identity or authority;
- declare an external effect realized without observation.

## Tunnel 3 execution chain

`PROPOSE -> CLASSIFY -> DETERMINE -> ADMIT/DENY -> ACTUATE -> OBSERVE -> RECEIPT -> EVENT`

A model output is a cognitive occurrence. It becomes an externally consequential state transition only after it crosses the existing mutation membrane.

## Self-hosted runner boundary

The workflow targets labels:

`self-hosted, linux, ollamaself`

This label selection is a routing constraint, not an authority grant.

The workflow is intentionally bounded to:

1. checkout;
2. run the existing mutation membrane tests;
3. run OLLAMASELF boundary tests;
4. emit a launch proposal.

It does not automatically invoke a local model or perform host mutation.

## Verification boundary

A successful GitHub workflow proves only that the bounded workflow executed on a matching runner and produced its declared outputs. It does not prove:

- that a particular Ollama model exists;
- that the model output is authoritative;
- that a proposed transition was admitted;
- that an external effect occurred;
- that the runner itself is constitutionally sovereign.

Those claims require their own evidence and observation boundaries.
