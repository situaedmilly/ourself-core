# Tunnel 1 — Constitutional Mutation Membrane

Purpose: establish a minimal executable contract for:

PROPOSAL → NORMALIZE → DETERMINE → ADMIT/DENY → ACTUATE → OBSERVE → RECEIPT

The first tunnel deliberately tests state mutation only. Capability, authority, identity, and governance mutation remain hostile branches for later chambers.

Invariant:

CAPABILITY TO PROPOSE ≠ AUTHORITY TO ACTUATE

And:

PROPOSED_TRANSITION ≠ AUTHORIZED_TRANSITION ≠ ACTUATED_EFFECT ≠ OBSERVED_EFFECT
