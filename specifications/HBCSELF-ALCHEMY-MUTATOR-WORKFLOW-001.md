## 13 · Recorded Ambiguity · The Terminal `STOP.`

**Distinction:** `SELF-DIST-01K3MSTOPAMBIGUITY01000000` — declared in Delta-621, cited here

The source command terminates with the bare token `STOP.`

`STOP_SIGNAL`. It was therefore read as a declaration-list terminator, consistent with the
prior command's `STOP AFTER: COLD REVIEW + SPECIFICATION ARTIFACTS + TERMINAL VERDICT`, and

This is recorded, not resolved. It is precisely the near-miss class the boot protocol exists to
catch, and the distinction it produces is:

```text

```

If a halt was intended, the command should be re-sent carrying the exact marker `STOP_SIGNAL`,
under which boot rule 7 overrides all other signals and this session fails closed.
