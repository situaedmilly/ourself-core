# IDENTITYMOAT + HELPMOAT — Runtime Contract v0.1

## Constitutional ordering

OURSELF is the declared authority domain. IDENTITYMOAT authenticates a local principal's control of a scoped cryptographic identity. HELPMOAT constrains what cognitive assistance may do. Neither runtime creates constitutional authority.

IDENTITY_PROOF != AUTHORITY
HELP_OUTPUT != AUTHORIZATION
PROPOSAL != ADMISSION
ADMISSION != ACTUATION
RECEIPT != EFFECT

## IDENTITYMOAT state model

UNENROLLED -> KEY_CREATED -> ENROLLED -> CHALLENGE_ISSUED -> PROOF_VERIFIED

Revocation is terminal for the enrolled key identity. Enrollment requires a Secure Enclave P-256 signing key whose private key is non-exportable and protected by macOS biometric-current-set Keychain access control. The verifier binds the proof to a short-lived nonce, audience, scope and identity record. Challenges are one-use.

The local identity record's identity_attestation remains UNVERIFIED until an independent identity authority supplies verifiable attestation. Local Touch ID proves that the enrolled device's biometric policy was satisfied; it does not independently prove a legal name, founding-council membership, unanimous assent, root custody, or authority to sign.

## HELPMOAT action classes

| Class | Runtime disposition | Effect |
|---|---|---|
| EXPLAIN / SUMMARIZE / DRAFT | ALLOW_HELP_ONLY | None |
| PROPOSE | ALLOW_PROPOSAL_ONLY | None |
| INSPECT | ALLOW_READ_ONLY only with explicit source | None |
| EXECUTE / MUTATE / DELETE | DENY | None |
| NETWORK / CREDENTIAL_ACCESS | DENY | None |
| IDENTITY_ENROLL / AUTHORITY_GRANT | DENY | None |
| BROKER_ACTUATION / BOOT / RESTORE | DENY | None |

An independently authorized execution membrane may separately evaluate a proposal. HELPMOAT never calls that membrane and never signs an admission.

## Activation boundaries

- Native key enrollment has not been performed.
- No private key is generated by automated tests.
- No production identity record is asserted.
- No founder constitutional status is independently attested.
- No HELPMOAT effect capability exists.
- No PipePortal, launchd, Keychain, broker, Pi or VM state is modified by this implementation.
