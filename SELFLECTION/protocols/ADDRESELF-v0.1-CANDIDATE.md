# addreSELF · v0.1 CANDIDATE

An `addreSELF` is a namespace-bound resolution relation for addressable Matter. It answers how a particular Matter object can be distinguished, resolved, and re-encountered under a declared namespace without smuggling canonical identity or proof into the address itself.

## Required surfaces

- address reference
- namespace identity and scope
- subject Matter reference
- distinction-basis reference
- origin witness reference
- lineage-head reference
- issuer reference
- issuance time
- addressability standing
- recognition standing

## Required properties under WOMB-R1

1. Distinguishability
2. Resolution
3. Stability
4. Scope
5. Provenance
6. Non-collision within declared scope
7. Revocability
8. Reconciliability

The construction algorithm is intentionally NOT frozen in v0.1.

## Hard laws

`addreSELF != Identifier`  
`addreSELF != IdentityVerdict`  
`addreSELF != Proof`  
`LocalAddress != GlobalRecognition`  
`LocallyDistinguishable != GloballyUnique`  
`AddressIssued != IdentityRegistered`
