## Governing doctrine

**OURSELF OPERATING SYSTEM (OSOS) is the parent architectural and constitutional authority.** It is not synonymous with OURSELF ECOSYSTEM, OURSELFDAEMON, OURPROCESSORSELF, or a Linux-based runtime. The ecosystem, daemons, processors, models, bridges, and host operating systems are governed implementations or execution environments beneath OSOS.

One constitutional root. Multiple platform-specific execution environments. Independently evaluated authority. Independently witnessed effects. Recoverable continuity.

Owner authority is established through explicit ownership enrollment and protected key-management procedures—not inferred from physical possession, a username, device registration, or successful login. Witness independence requires evidence of protected key custody, a separate execution boundary, and an evidence channel unavailable for alteration by the process being witnessed.

See the [initial root reconciliation](architecture/OURSELF-OS-2051/ROOT-RECONCILIATION-2026-11-02.md) and [subsystem registry](architecture/OURSELF-OS-2051/SUBSYSTEM-REGISTRY.yaml). The canonical root decision remains pending.
