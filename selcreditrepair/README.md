# SELFCREDITREPAIR Runtime Primitive v0.1

Bounded realization of SELFMOAT / REVERSELF inside OURSELF core.

## Runtime law
OBSERVE -> DIFFERENTIATE -> BIND -> REVERSE -> PROPOSE -> HUMAN AUTHORIZATION -> ADMIT -> ACTUATE -> OBSERVE -> VERIFY.

## Authority boundary
The agent may observe, differentiate, bind, reverse, and propose. Agent authority is NONE. Authorization must be an explicit HUMAN artifact matching both case_id and action_ref.

## Evidence boundary
A receipt is recorded but never treated as proof of effect. VERIFIED is reachable only after post-actuation observation and an explicit verification result.

## External-effect boundary
No credit-bureau connector is included in this primitive. Actuation is dependency-injected; this runtime does not claim an external bureau mutation occurred.
